GUIDE D'UTILISATION

Comment utiliser l'application ?

L'application a été conçue pour être rapide, intuitive et accessible à tous les citoyens de Dakhla, sans création de compte complexe.

01

Connexion par E-mail & Code

Aucun mot de passe à retenir. Pour accéder à l'application :

  • Saisissez votre adresse e-mail.
  • Recevez instantanément un code de vérification à 6 chiffres.
  • Entrez le code pour valider votre accès en toute sécurité.
02

Envoyer un signalement

Vous constatez un problème environnemental ? Signalez-le en 4 éléments simples :

  • Une photo : prenez le problème en photo sur place.
  • La localisation : position automatique ou manuelle.
  • Le type : déchets, éclairage, espace vert, etc.
  • Une description : facultative pour ajouter des détails.
03

Suivre via « Mes signalements »

Restez informé de l'évolution de vos contributions citoyennes à tout moment :

  • Ouvrez l'onglet « Mes signalements » dans l'application.
  • Consultez l'historique de tous vos envois.
  • Vérifiez le statut en temps réel de chaque dossier.
TRANSPARENCE & SUIVI

Comprendre l'espace « Mes signalements »

Une fois votre signalement envoyé depuis l'application, il apparaît automatiquement dans votre rubrique personnelle « Mes signalements ». Vous pouvez y suivre chaque étape de sa prise en charge grâce à des indicateurs clairs :

En attente

Votre signalement a bien été reçu et attend d'être examiné.

En cours

Les équipes concernées ont pris en charge le signalement.

Résolu

L'intervention est terminée et le problème a été réglé.

TÉLÉCHARGEMENT & INSTALLATION

Installez Dakhla Environnement sur votre appareil

Téléchargez le package officiel de l'application et suivez les étapes ci-dessous pour l'installer facilement.

1

Télécharger

Cliquez sur le bouton ci-dessous pour récupérer le fichier .ZIP.

2

Extraire le fichier

Ouvrez vos téléchargements et décompressez (extrayez) le dossier ZIP.

3

Lancer l'installation

Ouvrez le fichier d'installation contenu dans le dossier extrait.

4

Se connecter

Ouvrez l'application et entrez votre e-mail pour recevoir votre code à 6 chiffres.
